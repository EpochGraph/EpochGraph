# EpochGraph

[EpochGraph.com](https://EpochGraph.com) の公開用の静的 Web サイトです。Wikidata と Wikipedia から作る、時系列の 3D ナレッジグラフの歴史サイトです。

## このリポジトリについて

- ここには、ビルドしたあとのファイル（HTML・JSON）だけを置きます。手で直さないでください。ファイルは、非公開のリポジトリにある作成システム（EpochForge）が作ります
- 運営者が OK を出した期だけを入れます。更新は PR で行い、マージすると Cloudflare Pages が EpochGraph.com に公開します

- 項目と事実: [Wikidata](https://www.wikidata.org/)（[CC0](https://creativecommons.org/publicdomain/zero/1.0/deed.ja)）

- 画像: [Wikimedia Commons](https://commons.wikimedia.org/)。それぞれのファイルのライセンスに従います。このリポジトリには置かず、Commons から読み込みます
